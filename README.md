# Rion Win 11 Free

Windows 11 x64 driver installation, device drivers, utilities, Windows app/runtime installers, game capture, Win32 Separation Control and MMCSS.

Only Free builds are supported. BIOS, advanced GPU controls, customer builds and the power editor are excluded. Repository history is retained.

Build with .NET 8 and tools/Build.ps1. Publish with tools/Publish.ps1, then tools/Build-Installer.ps1 with NSIS 3.12. Setup embeds .NET and all core files and never downloads a GitHub payload. Optional utilities and drivers require their own downloads.

See LICENSE, THIRD_PARTY_NOTICES.md and the Files release for downloads, checksums and validation.
